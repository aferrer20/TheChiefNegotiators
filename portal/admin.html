// Form Submission

1. Formspree — receive form submissions

Routes Reserve, Want‑to‑Buy, and Contact submissions to sales@thechiefnegotiators.com.

  1. Sign up at formspree.io with sales@thechiefnegotiators.com.
  2. Create four forms. Suggested names: Reservation, Want to Buy, Contact, BOM Request.
  3. Each form has an endpoint that looks like https://formspree.io/f/xxxxxxxx.
  4. Open static/config.js and paste each URL into the matching slot:
formspree: {
  reservation: "https://formspree.io/f/xxxxxxxx",
  wtb:         "https://formspree.io/f/yyyyyyyy",
  contact:     "https://formspree.io/f/zzzzzzzz",
  bom:         "https://formspree.io/f/wwwwwwww",
},

Redeploy and submit a test from each form. Submissions land in the Formspree dashboard and Dan's inbox. Local backup still logs to the Reservations and WTB tabs in this console.

2. Google Sheets — live inventory source

The public Inventory page reads daily updates straight from your sheet.

  1. Create a new Google Sheet. Name it whatever you want, e.g. TCN GPU Inventory.
  2. Row 1 must be the header row, with EXACTLY these column names:
Model Form Factor Quantity Condition Lead Days Region Price Status
H100SXM564New14North AmericaRequestactive
H200HGX8New0EMEARequestactive
B200HGX4New45APACRequestactive

Optional columns: Notes, Lead Text (overrides Lead Days, e.g. "Immediate"), Updated, BOM Link (URL to a Google Drive PDF; if filled, the BOM button shows a "doc available" state and the link is included in the request email). Status of "inactive" hides a row.

  1. In the sheet: File → Share → Publish to web.
  2. Select the inventory tab and choose Comma-separated values (.csv).
  3. Click Publish. Copy the URL it gives you.
  4. Paste it into static/config.js:
inventorySheetCsvUrl: "https://docs.google.com/spreadsheets/d/e/.../pub?output=csv",

Redeploy. The Inventory page now reads your sheet every 60 seconds. To update stock: edit the sheet and save. No code changes needed.

3. The Exchange and the Prospect Desk engine

The exchange runs in preview mode on sample data until Supabase is connected. The Prospect Desk needs the Netlify function for AI drafts on your domain.

  1. Create a free project at supabase.com. In SQL Editor, run supabase/schema.sql.
  2. Authentication → URL Configuration: set Site URL to your domain and add https://yourdomain/exchange.html and /admin.html as redirect URLs.
  3. Paste the project URL and anon key into exchange in static/config.js.
  4. Apply on your own exchange with the sales email, click the sign-in link, then run the admin bootstrap line at the bottom of the schema.
  5. On Netlify, set ANTHROPIC_API_KEY (and optionally DESK_KEY). The desk calls /.netlify/functions/prospect.

Full walkthrough: EXCHANGE_SETUP.md in the project folder.

4. Deploy on Netlify

  1. Drag the project folder onto app.netlify.com/drop for instant deploy, or connect a Git repo for continuous deployment.
  2. The portal is served at portal.thechiefnegotiators.com, a domain alias on the same Netlify site (see _redirects).
  3. Whenever you edit config.js, redeploy. Changes to the Google Sheet itself do not require a redeploy.
